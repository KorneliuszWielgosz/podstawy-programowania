
# Podstawy programowania

Zadania wykonane w językach Python i C#.

## Zadanie 1 — Kalkulator
Program wykonuje dodawanie, odejmowanie, mnożenie i dzielenie dwóch liczb.

## Zadanie 2 — Konwerter temperatur
Program przelicza temperaturę ze stopni Celsjusza na Fahrenheita oraz odwrotnie.

## Zadanie 3 — Średnia ocen
Program oblicza średnią z podanych ocen i informuje, czy student zaliczył przedmiot. Zaliczenie następuje przy średniej co najmniej 3.0.

## Pliki Python
- `kalkulator.py`
- `temperatury.py`
- `srednia_ocen.py`

## Pliki C#
- `CSharp/Kalkulator.cs`
- `CSharp/Temperatury.cs`
- `CSharp/SredniaOcen.cs`
